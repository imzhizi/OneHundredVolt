# v1.5 — Android OTA 应用内更新

> 目标版本：v1.5
> 当前版本：v1.4
> 文档状态：开发中

## 背景

用户需要手动去 GitHub 下载新版 APK，流程繁琐且 GitHub 在国内访问速度慢。需要实现：
1. 自动发布 Release APK 到 GitHub（CI/CD）
2. App 内检测新版本并提示更新
3. 通过国内镜像站加速下载
4. 下载完成后引导安装

## 方案

### 1. CI/CD 自动发布

**文件**: `.github/workflows/release.yml`

- 触发: push tag `v*`
- 流程: checkout -> JDK17 -> decode keystore -> assembleRelease -> create GitHub Release
- Release body 包含国内镜像下载地址 (ghfast.com)
- 需配置 GitHub Secrets: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`

### 2. App 端更新模块

**文件**: `androidApp/.../platform/AppUpdater.kt`

三层功能:
- **检测**: GET `/repos/imzhizi/OneHundredVolt/releases/latest`，解析 versionCode 比较
- **下载**: OkHttp 下载到外部 Files 目录，Flow 进度回调
- **安装**: FileProvider URI + Intent.ACTION_VIEW 打开系统安装器

**文件**: `androidApp/.../components/UpdateDialog.kt`

三态弹窗 UI:
1. 发现新版本 -> 显示 changelog + 文件大小 -> [稍后更新] [立即更新]
2. 下载中 -> LinearProgressIndicator + 已下载/总大小 + 百分比
3. 下载完成 -> [立即安装] 按钮

### 3. 设置页入口

**文件**: `SettingsScreen.kt`

"关于" section 新增「检查更新」按钮，支持状态切换:
- 默认: "检查更新" 按钮
- 检查中: loading spinner
- 有更新: 弹出 UpdateDialog
- 已是最新: 绿色 "已是最新版"

### 4. 启动静默检查

**文件**: `OhvApplication.kt`

onCreate 中启动协程静默调用 checkForUpdate()，仅打日志不弹窗。

### 5. 权限与配置

**AndroidManifest.xml**:
- `REQUEST_INSTALL_PACKAGES` - 安装 APK 权限
- `ACCESS_NETWORK_STATE` - 网络状态判断
- FileProvider - 安装时 URI 授权

**res/xml/file_paths.xml**: FileProvider 路径配置

## 国内镜像站

使用 `ghfast.com` 作为 GitHub Releases 加速 CDN:

```
https://ghfast.com/https://github.com/{repo}/releases/download/{tag}/{apk-name}
```

## 使用方式

### 发布新版本
```bash
# 1. 更新 build.gradle.kts 中的 versionCode / versionName
# 2. 提交代码
git add . && git commit -m "feat: ..."
git push

# 3. 打 tag 触发 CI/CD
git tag v1.5 && git push --tags
```

GitHub Actions 会自动构建 release APK 并创建 GitHub Release。
