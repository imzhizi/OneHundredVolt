# v1.1 — iOS 修复优化 + MiniPlayer + 音频缓存

> 文档状态：✅ 已全部实现（v1.1.0）
> 版本记录见：`docs/CHANGELOG.md`

## Context

用户在使用 v1.0 过程中发现多个问题，涉及：MiniPlayer 状态恢复、时长显示格式、音频缓存、UI 间距、播放列表交互、专辑详情排版等。本次 v1.1 集中修复并优化这些问题。

---

## 问题汇总与方案

### 1. MiniPlayer 进度重启后丢失 + 播放按钮失效

**根因**：
- `restorePlaylist()` 恢复了 `currentItem` 和 `playlist`，但 `currentTime = 0`、`duration = 0`，导致 `progressRatio = 0`
- 点击播放按钮调 `resume()`，但 `player`（AVPlayer）为 nil，`isPlaying` 不更新

**方案**：
- `restorePlaylist()` 中从 `PlaybackProgressStore` 读取进度设置 `currentTime`，从 `AudioItem.duration` 恢复 `duration`
- `togglePlayPause()`：若 `player == nil` 且有 `currentItem`，调 `loadAndPlay(item:)` 而非 `resume()`

**文件**：`Services/AudioPlayerService.swift`

---

### 2. 时长格式：列表只显示总分钟数，播放页显示完整时长

**规则**：
- 列表（播放列表 + 专辑列表）：只显示总分钟数，不换算小时，不显示秒
  - `3661s → "61 分钟"`，`45s → "1 分钟"`
- 播放页（PlayerView）：保留 `.formatted`（`mm:ss` / `h:mm:ss`）

**方案**：`Extensions.swift` 新增 `var minutesOnly: String`（`Int(self) / 60` 分钟）；列表中替换 `.formatted` → `.minutesOnly`

**文件**：`Shared/Extensions.swift`、`Features/Home/HomeView.swift`（PlaylistRowView）、`Features/Album/AlbumDetailView.swift`

---

### 3. 音频缓存：单集缓存，重启快速恢复播放

**方案**：新建 `AudioCacheService`（单例）：
- 缓存目录：`Caches/AudioCache/{postId}`（按 postId 命名文件）
- `cachedURL(for postId:) -> URL?`：检查本地缓存
- `cacheAudio(from remoteURL: URL, postId: String) async`：后台下载并缓存
- `removeCache(for postId:)`：删除单个缓存文件
- 缓存大小限制：500MB，超出时 LRU 淘汰

`loadAndPlay(item:)` 流程：
1. 检查本地缓存 → 有则直接用本地 URL（无需网络请求）
2. 无缓存 → fetch 远程 URL → 播放的同时异步下载缓存

缓存清除时机：
- 播放列表删除某集（`onDelete` 回调）
- 播放完成（`handlePlaybackFinished`）

**文件**：新建 `Services/AudioCacheService.swift`，修改 `Services/AudioPlayerService.swift`，修改 `Features/Home/HomeView.swift`

### 6 & 7. 播放列表 + 专辑列表：统一行布局

**播放列表行**（PlaylistRowView）：
```
┌─────────────────────────────────────────────────────────┐
│ ▌  ┌──────┐  标题（截断...）              ≡ (拖拽手柄) │
│    │ 封面 │  45 分钟                                    │
│    │[图标]│                                             │
│    └──────┘                                             │
└─────────────────────────────────────────────────────────┘
  左侧 3px 竖条（当前项）
  封面上叠加图标（见下方）
  左划 → 删除
```

**专辑列表行**（AlbumDetailView audioRow）：
```
┌─────────────────────────────────────────────────────────┐
│    ┌──────┐  标题（截断...）               +   ▶       │
│    │ 封面 │  45 分钟                                    │
│    │[图标]│                                             │
│    └──────┘                                             │
└─────────────────────────────────────────────────────────┘
```

**封面状态指示器**（ZStack 叠加，仅当前项或已完成项显示遮罩）：

| 状态 | 遮罩 | 图标 | 整行样式 |
|------|------|------|---------|
| 默认 | 无 | 无 | 正常 |
| 加载中 | 半透明黑 | ProgressView | 正常 |
| 播放中 | 半透明黑 | waveform 动画 | accent 高亮 |
| 暂停中 | 半透明黑 | pause.fill | accent 高亮 |
| 已完成 | 半透明黑 | checkmark | 整行 opacity 0.4 |

**播放列表拖拽**：改为 `List + .listStyle(.plain)` 以支持系统 `.onMove` 拖拽手柄，自定义 row 背景和分隔线保持现有风格

**文件**：`Features/Home/HomeView.swift`（PlaylistRowView）、`Features/Album/AlbumDetailView.swift`

### 8. 播放列表：正在播放的单集被点击不应有响应

**方案**：`PlaylistRowView.onTapGesture` 加 `guard !isCurrent else { return }`

**文件**：`Features/Home/HomeView.swift`（PlaylistRowView）

---

### 9. 专辑「全部播放」：追加到队列末尾

**现状**：`player.play(playlist:startAt:)` 直接覆盖整个播放列表。

**方案**：
- `AlbumDetailView` 的"全部播放"按钮改为：将专辑中尚未在队列中的单集追加到队列末尾，然后立即跳到该专辑第一集播放
- `AudioPlayerService` 新增 `appendAndPlay(items: [AudioItem])` 方法：
  1. 过滤已在 playlist 中的项
  2. 将剩余项 append 到 playlist 末尾
  3. 将第一项移到 playlist[0]（或直接 playImmediately）

**文件**：`Services/AudioPlayerService.swift`、`Features/Album/AlbumDetailView.swift`
